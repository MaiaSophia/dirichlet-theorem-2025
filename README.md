## Contents

- **Statement of Dirichlet's theorem:** every arithmetic progression
  a, a + m, a + 2m, … with gcd(a, m) = 1 contains infinitely many primes.
- **Natural and analytic (Dirichlet) density**, with the example of primes
  whose first digit is 1.
- **Proof:** the primes p ≡ a mod m have analytic density 1/φ(m), using
  Dirichlet characters and Dirichlet L-functions, so primes are evenly
  distributed among the residue classes coprime to m.
- **Application:** solutions of X² = a modulo infinitely many primes
  (quadratic residues).
